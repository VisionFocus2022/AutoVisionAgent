# run-eval-experiment：评测实验与留档

> 原子范围：一个实验问题（一组参数/两种口径的对比），产出可复现脚本+数字结论。

## 标准动线（按序执行，引用先例）

1. **先建 oracle 上界**：优化前先测上界（GT 提示/紧裁剪）——上界≈现状=停手找新杠杆，别在非瓶颈烧轮次（W47 范式）
2. **样本量 ≥ val 规模**：策略/参数类实验 ≥100 样本（W52：12 图误判中性，162 图翻案 +0.025）；小样本结论必须标注置信度
3. **扫悬崖不止甜点**：盒/半径类参数全域扫描并报告悬崖点与零产出数（零产出比 mean 更灵敏的哨兵，W52/W53）
4. **脚本入 scripts/**：`scripts/exp_*.py` 参数化（--ckpt/--manifest/--n 可复现，先例 `eval_sam3_accuracy.py`）；不改生产代码
5. **证据门**：结论改动生产前 Δ≥0.01 且跨口径复现两次才落产（`_best_mask_near` 先例）
6. **留档**：负结果同样留档（commit 正文或 docs/prd）——"负结果关单"是合法产出（22× 查表化、objectness focal 两例）
7. **归因拆解**：多实例选择型验收先报"命中率×命中质量"二元分解，mean 会被零命中掩盖（W50）
