## 1. 背景与目标

AC-010 wave3 核对推翻原推断：SKolpha「切割线」真身=**裁剪标注（X 键切分工具）**——画一条裁剪线，把既有矩形/多边形一分为二，原形删除、新形生成。D-23 裁决 B 立项 FR-011。本波把该真缺口按官方规格（chm page_159）落进 AVA。

## 2. 功能需求 (FR)

- **FR-1 纯几何切分函数**（`labeling/crop.py`，纯函数零依赖）：
  - `split_rectangle_by_line(rect2, a, b)`：过 a-b 的**无限直线**切矩形（归一化角点输入）。命中两条宽（上/下边）→ 取两交点连线中点的 **x** 作纵切，输出两个矩形；命中两条高（左/右边）→ 中点 **y** 横切；单交点/相邻边/共线/切线过角/两点重合 → **None（不切，SKolpha 同款口径）**。
  - `split_polygon_by_line(points, a, b)`：开放环（≥3 点，自动剥收尾重复点）；直线与边**恰 2 个严格交点**→ 半平面分割为两片（各 ≥3 点）；**>2 交点（非凸多段穿越）v1 诚实返回 None**（SKolpha 支持切若干片——多片留 v2，见 §4）；任一顶点恰在线上（side=0）→ None（微移即可，避免歧义）；全部同侧 → None。
- **FR-2 CROP 工具模式**（枚举第 8 员，**工具型**同 EDIT：无 labeler、`manual_modes()` 不变（仍 4）、不落盘、io_labelme 零涉及）：
  - 控制器两点交互：第 1 左键定起点 → 移动中画布实时预览（**复用 CUT_LINE 虚线渲染**，零画布渲染改动）→ 第 2 左键提交；右键/Esc 取消。
  - 提交语义：对画布**全部可切形状**（RECTANGLE/OPERATION 二点矩形、POLYGON ≥3 点；CUT_LINE/EDIT 态形状不参与）逐个求切分；被切者原形删除、新形生成（label/color 继承）；**一次裁剪=一步撤销**（canvas 新 API `replace_shapes`：单 `_save_state` 批量替换）；无形状被切 → 无操作（SKolpha「都不裁剪」同款）。
- **FR-3 页面接线**：`_MODES` 增 `(CROP, "裁剪", "X")`（按钮+快捷键数据驱动自动接线）；`_DRAW_MODES` 增 CROP（十字光标）；i18n `"裁剪": "Crop"`（W20 完整性守卫自动覆盖）。
- **FR-4 守卫增量生长**（FB-016 口径）：枚举全集/模式表数量断言随批更新。
