## 5. 风险与假设（含探索三栏）

- **已知（确证）**: ①Nuitka Py3.9 onefile 65MB，函数签名/调用链可从常量+局部变量簇重组（SAM 前案验证）；②明文层=9 类训练模板+labelme 定制+i18n+chm；③default.yaml Fernet 加密；④dotnet-decompile 技能工具链在手（py_scan.py 等 6 脚本）。
- **假设（待验证·不成立则…）**: ①训练引擎=OpenMMLab 系 → 否则按自研管线挖（.py config 仍给出数据流骨架）；②UI=PySide6+CoreUI 风格控件库 → 仅影响表述不影响主线；③Fernet 密钥在常量区 → 否则 default.yaml 不可解（AC-004 走诚实降级）；④函数级重建对四大主线可行 → Nuitka 混合 C 段以常量+调用约定推断并标注置信。
- **未知**: Phase 0 四项已全部裁决（深度/范围/动静/批次），无残留未知。
- **风险**: ①65MB 常量区体量大 → py_scan 头1MB+尾8MB 定标+模块表定位后定向挖掘；②chm 为 GBK 中文 → 转码后处理；③exe 解包（onefile zstd 载荷）可能需一次性解到 %TEMP% 供全量扫描 → 磁盘占用 ~500MB 级，用后即删。

## 6. 实现思路

- **手法**: 波1 = py_scan 模块表/特征扫描 + languageFile.json/programFile.json 脚本化解析 + `hh.exe -decompile` 解 chm（GBK→UTF-8）+ TrainConfigs 模板逐类摘要 → 功能全图。波2 = 按波1 定位的业务模块做函数级常量邻域 dump（±1.4KB 惯例）重组签名与调用链；Fernet 密钥用 44 字符 base64 形态特征在常量区全文搜。
- **复用**: dotnet-decompile 技能全部既有工具与坑集（Nuitka 特征窗口/GBK 转码/模块表正则）；既往 SAM 标注取证结论（box prompt+∩合并）直接并入波2 标注主线。
- **注意**: 报告语言中文；不自动 commit；动态观察仅启动 exe 看日志/产物，不改安装目录。
