# Roadmap：AutoVisionAgent 可信增强程序（P-AVA-TRUST）

- 版本：v1.0（2026-09-29 立项；产品侧输入：docs/product-plan-autovisionagent-2026Q4.md）
- 状态：🟢 进行中（Wave 1 待启动）
- 程序目标：把"离线工业视觉检测一体化工作站"从**功能完备**推进到**能力可信**——
  UI 暴露的每一项能力要么真实、要么显式拦截；模型资产/部署验证/评估建议
  三条闭环补齐。
- 程序级 NFR：
  - N1 主门禁全绿（1279+ 用例、覆盖 ≥92%、ruff 0）——每波末不可回退线
  - N2 UIA 全套件通过率 ≥95%（发版时单跑一次干净记录）
  - N3 离线可用：任何新能力在无外网工位可用（资产随包判例延续）
  - N4 每波独立可发版（exe 重建+PYZ 复验+UIA 冒烟为发版三件套）

## P0 立项要素

- **判型**：存量增强型，**治理前置**——第一波先还"真实度债"（用户连续
  三次报障的共同根因），再扩功能广度。排序理由（三原则）：①依赖拓扑：
  模型资产页(1.2)依赖训练真实度收口(1.1/1.3)；②降险前置：AMP 异步化
  (1.4)消灭已知阻塞形态；③价值切片：每项独立可验收可发版。
- **立项预验尸**（"三个月后废了，死因是什么"）：
  1. 单人带宽被日常报障吃光 → 缓解：报障即修纪律（本会话模式已验证）+
     每波切片小到 1-2 会话窗口
  2. 相机硬件不落地拖死第三波 → 缓解：3.4 悬置于决策台账（D-2），不阻塞
     前波
  3. ultralytics 升级破坏训练适配器 → 缓解：适配器隔离层已在；升级前跑
     e2e 冒烟（NFR 纪律）
  4. UIA 环境脆弱（锁屏/远程会话）→ 缓解：Invoke 通道+语言钉已固化；
     发版门禁单跑纪律
- **存量归编**：W65-W70 六批在途改动（向导链/持久化/真训练/回归修复）
  属本程序前置成果，先行提交入库（阻塞登记 B-1）。

## 波次分解（滚动窗口：近细远粗）

### Wave 1｜可信训练与模型资产（定径：2-3 周内，≈3 个会话窗口）

| 行 | 事项 | 定档预估 | DoD（波末先验） |
|---|---|---|---|
| W1-1 | 训练逐轮进度与曲线（适配器逐轮回调：loss/epoch/剩余时间→训练页实时曲线） | L2（并发/线程模型必答） | UIA：训练中 ≥N 进度点+曲线实时增长；中断后 UI 状态复位 |
| W1-2 | 训练历史与模型资产页（历史列表+一键加载推理+模型卡） | L2 | UIA：训练完成→历史出现→一键加载→推理出结果；模型卡含类别表/输入尺寸 |
| W1-3 | 模拟训练彻底显式化（非真任务下拉灰显+说明+点开始显式确认） | L1-L2 | UIA：模拟任务→显式确认出现；单测：门禁守护 |
| W1-4 | AMP 预检异步化+幽灵训练观察收口 | L1 | 预检在 worker；挂账项若复现即抓栈修 |
| W1-5 | 首启体验：安装参数配置初始密码（去 txt 明文交付） | L1 | 无网新工位：--init-pwd 参数生效；txt 不再生成（或即删提示） |
| W1-6 | 小数据训练默认超参修复（W71 实测：optimizer=auto 默认 lr 12 图上未起，零检出死模型；同数据 lr0=0.01 SGD 即 mAP50 0.0075→0.506） | L2 | ✅ 完成（2026-10-06）：默认 SGD lr0=0.01 + N≤50 轮数自适应 100 + 完成态 P/R/mAP50 显示 + yolov8n 随包；DoD exe 实跑 12 图案例 mAP50=0.51>0.3，P=1.00/R=0.35；PRD docs/prd-w1-6-small-data-hyperparams.md |

**Wave 1 整体 DoD**：N1-N4 全过；极柱案例走向导链训练全程"零模拟、
零无反馈等待"；用户实测一次全链并认可。

### Wave 2｜部署闭环与数据增强（细化推迟到 Wave 1 末——滚动窗口）

行：ONNX 一致性校验+模型卡随包 / 评估增强（PR 曲线+阈值调优选荐）/
数据增强管线 / cls 真训练（**D-1 待裁决，默认不提前**）/ 缺陷生成一期。

### Wave 3｜体系化与规模化（远粗）

行：检测报告 PDF / 项目包 2.0 / gRPC serving 产品化 / 相机采集（D-2
外部闸门）/ 无监督异常检测（立项前需用户验证）。
