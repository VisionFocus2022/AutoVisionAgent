# PRD：矩形内分割松框悬崖优化（W54 · lite）

- 档位：🟡 L2（自治 S1+S3：用户引用 W53 悬崖结论并指令「对这个进行优化」）
- 确定性：中高——扫描方法论定（val 162 全量），最优策略待测；影响半径：小（至多 `predict_point_in_box` 一处 + 测试守门）；可逆：双向门

## 1. 背景与目标

W53 实测（val 162 · GT 质心锚）：矩形内分割紧框 0.755（极柱域 SAM3 最强口径），但盒外扩 m=8 即砍半（0.486）、m=16 崩（0.275）、m=64 仅 0.136——盒提示语义随盒大小质变。固定紧提示混合臂（点击±16px + ∩用户盒）在 m≥16 兜底 0.546（=点击口径），但未测紧框 margin，且 0.546 远低于 0.755 顶点。

目标：找到提示推导/实例选择策略，使**松框场景显著超过 0.546 兜底线，同时紧框 0.755 不回归**。

## 2. 功能需求

- **FR-1 扫描脚本**：`scripts/exp_sam3_region_prompt_sweep.py`——val 162 全量，margin m∈{0,8,16,64}，策略臂：
  - **A1 固定紧提示**：prompt=点击±16px，nearest，∩用户盒（补 m=0/8，完整曲线）
  - **A2-f 比例缩放提示**：prompt=点击居中、半边长 = f×用户盒半边长（**下限 16px 防 W52 r=8 零实例**），f∈{0.5, 0.75}，nearest，∩用户盒
  - **A5 最小含点实例**：prompt=用户盒直发，选含点击点的最小实例（fallback nearest），∩用户盒
- **FR-2 证据门落产**：胜者满足 AC-2 → `predict_point_in_box` 落地（TDD 单测先行）；不满足 → 留档申报，生产零改动。
- **FR-3 复跑守门**：改后 UIA `test_sam3_labeling.py` 真窗复跑 + 主门禁全绿。

## 3. 验收标准

- **AC-1**：全部策略臂 × margin 数字落档 docs/tasks 回填（含逐臂时间与零产出）。
- **AC-2 证据门**：胜者同时满足 m=0 mean ≥ 0.74（紧框不回归，容差 0.015 噪声）**且** m=16 mean ≥ 0.45 **且** m=64 mean ≥ 0.30。不满足则按 FR-2 留档。
- **AC-3**：TDD RED→GREEN 或留档二选一有据。
- **AC-4**：UIA 3/3 真窗绿 + 主门禁 `pytest tests/ -q` 全绿。

## 4. 范围

**In**：扫描脚本、`labeling/sam3_adapter.py`（条件落产）、`tests/test_sam3_adapter.py`（条件）、docs 2 篇。
**Out**：SAM1 后端（`sam_adapter.py` 原版点+盒提示无此问题，不动）；笔刷模式（笔划外包盒天然紧）；UI 交互改造（提示文案/吸附辅助——若本轮纯算法优化不足再议）；pole-seg 双后端接入。

## 5. 风险与假设（三栏并入）

- 已知：W52 r=8 提示盒 16×16 触发 33 张零实例——A2 臂半边长下限 16px 硬护栏。
- 假设：比例缩放提示在紧框 margin≈GT 盒（保 0.755）、松框 margin 缩到近 GT（超 0.546）。
- 风险：①A5 最小含点实例在紧框 margin 可能选中噪声小片（AC-2 m=0 线直接否决）；②GPU 长跑 ~2h（后台+分段打印，SolidWorks 争抢显存）；③A2 若 f 敏感则需二轮补 f∈{0.6, 0.9}。

## 6. 实现思路

A1/A5 几乎零新增前向成本假设不成立（A1/A2 各自独立前向），总前向 ≈ 14×162≈2268 次 ~2h 后台跑。分析按「每 margin 最优臂 + 全 margin 一致性」选策略；落产只动 `predict_point_in_box` 内部（提示盒推导 + 选择复用 `_best_mask_near`/新选择器），签名与 modes 层契约不变。
