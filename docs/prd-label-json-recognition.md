# PRD：标注页同目录 JSON 识别加载 + 训练页样本统计回显（lite · L2）

> 档位：🟡L2 ｜ 版本：1.0 ｜ 日期：2026-09-21 ｜ 上游：用户指令；探索门禁已裁决（标注页=自动加载+●标记；训练页=样本统计回显）

## 1. 背景与目标

极柱数据集（1288 对 bmp+json 同目录）在标注页打开后画布恒空——`_load_by_index` 从不加载 `{图名}.json`（v7 审查记录在案的功能缺口）；训练页选定 data.yaml 后无任何样本反馈，用户无从确认数据集被识别。W59 已修数据管理统计口径（已标注 1288 ✓）。本 PRD 补齐另两页的「识别」面。

## 2. 功能需求（FR）

| # | 需求 | 说明 |
|---|------|------|
| FR-1 | 标注页 JSON 识别加载 | ① 打开文件夹时扫描同名 `{stem}.json` 存在性，文件列表项加「● 」前缀（只查存在不解析，1288 次 stat 可忽略）；② `_load_by_index`（打开/换图）后**画布为空**时自动经 `load_labelme_shapes` 载入同名 JSON，状态栏「已载入 N 标注」；画布非空（手绘在途）不合并不覆盖（W55 换图硬清空在前，载入在其后，语义无冲突）；③ 损坏 JSON 容错：跳过 + 状态栏提示原因，不炸；④ 实现走独立 mixin（page.py 已 800 行贴顶） |
| FR-2 | 训练页样本统计回显 | 选定 data.yaml 后解析（train/val 键→路径→images 目录文件计数），状态栏「数据集 train=N val=M」；yaml 缺键/路径无效 → 「数据集清单读取失败」+ 原因；只数文件不解析标签（轻量） |
| FR-3 | 单测守护 | 标注页：同名载入/非空不覆盖/无 JSON 不变/●标记/坏 JSON 容错；训练页：计数回显/坏 yaml 提示 |

## 3. 验收标准（AC）

| # | 标准 | 验证 |
|---|------|------|
| AC-1 | 真实极柱目录：文件列表 ● 标记 = 1288 项；首图画布载入其 JSON shapes；状态栏含「已载入」 | 无头复验 + 单测 |
| AC-2 | 手绘图换图再回：画布按该图 JSON 载入、无手绘残留（W55 语义保持） | 单测 |
| AC-3 | 训练页选导出 data.yaml → 状态栏 train/val 计数与实际目录一致 | 单测（真实导出产物） |
| AC-4 | 主门禁全绿 + page.py ≤800 行守卫 + ruff 0 | 门禁 |
| AC-5 | 无 JSON 目录行为不变；标注页既有用例（含 UIA 契约敏感的列表项文本断言）回归 | 全量门禁 |

## 4. 范围

**Out of Scope**：训练页直接选图像目录（内联导出）；标注合并语义（同名 JSON 与手绘共存时合并）；保存路径预填；`annotations/` 子目录形态在标注页的寻位（同目录为主口径，子目录可后续）。

## 5. 风险与假设

- ● 前缀改变文件列表项文本 → 既有断言 `item.text()` 的用例需回归（若有按文件名匹配的选择器需适配）；
- `load_labelme_shapes` 异常面未知 → 容错捕获 (OSError, ValueError, KeyError, json.JSONDecodeError)；
- 三栏并入：假设①用户「训练页识别不了」=无样本反馈（已裁决）；假设②●标记满足「可见识别」（已裁决）。

## 6. 实现思路

新 mixin `gui/pages/label/annotation_io_mixin.py`（扫描/载入/状态三职责）+ page.py 两处接线（打开文件夹、_load_by_index 尾部）+ 训练页 `_browse_data_yaml` 增统计回显（yaml 解析内联，无需新文件）。
