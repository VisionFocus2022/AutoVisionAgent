# SAM3 全图网格盒全覆盖分割 + 诚实降级提示 — 精简 PRD (L2)

> 版本: 1.0 | 日期: 2026-09-01 | 档位: 🟡 L2 | 确定性: 高（探索门禁已锁定两项方向） | 影响半径: 小（双向门：既有 detector 接缝上的纯增量，回滚=git revert；未命中硬触发器：无 DB/鉴权/删 API/破坏性接口） | 可逆性依据: 见 gating-matrix.md
> 前置：Phase 0 需求探索（精简三栏）已过探索门禁——用户两项裁决：优化方向=**网格盒全覆盖**；诚实降级提示=**需要**。

## 1. 背景与目标

- **背景**：点击「全图」（AUTO 模式，快捷键 G）时，极柱外观检 NG 样图（`101_20240611190141829441K3.bmp`）中大圆与背景轮廓零分割。根因：SAM3 全图 detector 走 PCS 文本概念通道（`sam3_adapter.build_amg_detector`，标签空时回退 "defect"），而 W47 极柱域实测通用概念词零命中（"defect"/"pole"/"dent"/"flaw" 全零，仅 "scratch"/"mark" 部分有效）——大圆/背景没有可表述的概念词。旧 SAM 的真 AMG 是「分割一切」，构成用户预期基线，两者落差即本缺陷。
- **目标**：
  1. 不输入概念词时，「全图」也能产出分割形状（不再零形状）。
  2. 仍出现零形状时给出诚实状态提示，而非静默。

## 2. 功能需求 (FR)

- **FR-001**: 网格盒全覆盖 detector —— 将图像划分为带重叠的网格盒，逐盒经 SAM3 盒提示分割（复用 `_run_instances` 的 boxes 通道），跨盒按 IoU 阈值去重合并；网格盒数量设上限控推理成本。`build_amg_detector(label="")` 返回网格 detector；label 非空时保留既有文本概念通道。 | 优先级 P0
- **FR-002**: 诚实降级提示 —— AUTO 模式一次执行产出 0 个形状时，状态栏显示提示（告知未分出结果 + 建议输入概念词或改用区域/点击模式），文案走 tr()，zh/en i18n 键对偶齐备。 | 优先级 P0

## 3. 验收标准 (AC)

- **AC-001**: 给定 SAM3 adapter 已加载，当以空标签构造 `build_amg_detector()` 并对测试图执行，应走盒提示通道（mock `_run_instances` 断言收到非空 boxes）且返回形状非空 [关联 FR-001]
- **AC-002**: 给定两个相邻网格盒产出同区域重复掩码（IoU ≥ 去重阈值），当合并结果，应只保留其一 [关联 FR-001]
- **AC-003**: 给定大尺寸图像（如 4000×3000），当生成网格，应盒数 ≤ 上限（默认 9）且各盒联合覆盖全图、相邻盒有重叠 [关联 FR-001]
- **AC-004**: 给定非空概念词标签（如 "scratch"），当执行全图，应仍走文本概念通道，既有行为不变 [关联 FR-001]
- **AC-005**: 给定检测器返回 0 形状，当执行「全图」，状态栏应显示降级提示文案；zh 与 en 字典均含新键 [关联 FR-002]
- **AC-006**: 主门禁 `.venv/Scripts/python.exe -m pytest` rc=0 且覆盖率 ≥92% 不降 [关联全部]

## 4. 范围

- ✅ **In Scope**: `labeling/sam3_adapter.py` 网格盒 detector（含网格生成纯函数与跨盒去重）；0 形状状态提示接线（`gui/pages/label/sam_session.py` 或 `labeling/modes/auto.py`）+ i18n zh/en 键；对应单元测试。
- ❌ **Out of Scope**: SAM3 微调/训练；「区域」「点击」模式行为；UIA 套件整体改造（既有 `test_sam3_auto_concept_flow` 走非空标签语义保持）；网格参数入配置 UI。

## 5. 风险与假设（含需求探索三栏）

- **已知（确证事实）**: ①SAM3 无点提示/无原生 AMG，仅 `text` + `input_boxes`（W46 grep site-packages 实证）；②W47 极柱域概念词零命中矩阵（见 `build_amg_detector` docstring）；③`_run_instances(boxes=...)` 盒提示通道已存在且是测试缝；④W53 实测紧盒提示 IoU 0.755——盒提示在本域有效。
- **假设（待验证 · 不成立则…）**: ①processor 支持单次前向多盒批量 → 否则逐盒循环推理（成本上升、功能不受损）；②默认 3×3 网格可覆盖极柱样图中的大圆/背景目标 → 否则调默认网格维度（参数本身可测）。
- **未知（Phase 0 已清空）**: 方向两项已由探索门禁裁决，无残留未知。
- **风险**: ①推理成本——9 盒最坏 9×1.4s≈13s（RTX 3060 单盒实测 1.4-1.5s）；缓解=批量前向若可行压到单次 + 状态栏可见进度；②网格边切穿目标致掩码截断；缓解=相邻盒重叠；③UIA 既有用例语义破坏；缓解=非空标签保留旧通道（AC-004 钉死）。

## 6. 实现思路

- **拟采用**: `build_amg_detector` 内按 label 分支——空标签 → 网格 detector（网格生成纯函数 + boxes 盒提示 + IoU 去重 + max_masks/min_area 过滤沿用）；非空标签 → 既有文本概念通道原样保留。
- **复用**: `_run_instances(image, boxes=...)` 单次前向通道；`_mask_to_polygon`；`build_amg_detector` 现有过滤/排序/Shape 转换尾段；W43 盒提示与掩码处理结论。
- **注意**: 新状态文案必须走 tr() 且 zh/en 键对偶（i18n 字面量守卫）；`page.py` ≤800 行守卫（接线做薄）；不触碰并行会话在途的 8 个改动文件；提交格式 `feat: W55 …`（波次以实际为准）。
