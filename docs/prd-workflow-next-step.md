# PRD：工作流「下一步」向导导航（lite · L2）

> 档位：🟡L2 ｜ 版本：1.0 ｜ 日期：2026-09-21 ｜ 探索门禁已裁决：链序=标注→数据管理→训练→推理（延伸确认）

## 1. 背景与目标

极柱工作流（标注→导出训练集→训练→推理）目前靠侧边导航手动找页。加「下一步」快捷按钮：当前环节完成即一键进下一环节，向导式流转；侧边导航保持不变（并行入口）。

## 2. 功能需求（FR）

| # | 需求 | 说明 |
|---|------|------|
| FR-1 | 通用跨页导航约定 | 页面可声明 `request_page = Signal(str)`；shell `add_page` 泛化挂接（有则 connect 到 `select`）——无信号页零侵入；权限/审计走 `select` 既有门（operator 无 train 页时被拒+审计，诚实行为，不改门） |
| FR-2 | 三处「下一步」按钮 | 标注页「下一步：数据管理」→ `data_manage`；数据管理「下一步：训练」→ `train`；训练页「下一步：推理」→ `predict`。accent 样式、工具栏显著位；标注页属性名避让既有 `btn_next`（下一张） |
| FR-3 | 单测 | shell 泛化挂接（有信号页 emit→切页；无信号页不受影响）；三按钮 emit 正确 key；operator 角色下 data_manage→train 被既有权限门拦截（不切换） |

## 3. AC

| # | 标准 |
|---|------|
| AC-1 | 标注页点「下一步：数据管理」→ shell 当前页切到数据管理（admin/engineer） |
| AC-2 | 数据管理→训练、训练→推理同律 |
| AC-3 | operator 点「下一步：训练」→ 不切换 + 「无权限访问该页面」+ 审计留痕（既有门行为回归） |
| AC-4 | 无 request_page 信号的页面注册不受影响；主门禁全绿 + ruff 0 + 行数守卫 |

## 4. 范围 / 5. 风险

Out of Scope：主页/评估/发布等其余页的下一步；链序可配置化；向导进度条 UI。
风险：三页行数守卫（label 697/data_manage 798/train 580——data_manage 贴顶 798/800！新增 ~8 行会破 → 需在 data_manage 内挪行或紧凑实现）；UIA 选择器无冲突（新按钮文案唯一）。

## 6. 实现思路

shell.add_page 尾部 +4 行泛化挂接；三页各 +Signal/按钮/emit（~8 行/页）；i18n 3 键；data_manage 行数紧张→按钮实现单行紧凑 + 必要时压缩既有注释。
