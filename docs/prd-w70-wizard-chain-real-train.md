# PRD-Lite：W70 向导链真训练 UIA 用例

- 版本：v1.0（2026-09-29）
- 档位：🟡L2（UIA 测试创建；门禁 1 裁决「预置已标注（推荐）」，收尾门禁并入本档）
- 用户原话：「创建UIA自动化测试，选择路径图片，从标注到下一步->数据管理->训练，
  点『开始训练』→ 真训练」

## 1. 背景与目标

向导链（W59b/W62/W63/W65/W69）修复散落五波，缺一条端到端回归把它们钉成
一条不可回退的用户路径。本用例把用户真实操作序列固化为 UIA 自动化。

## 2. FR 与 AC

| FR/步骤 | AC（全部 UIA 可观察） | 结果 |
|---|---|---|
| FR-1 标注起点 | 打开已标注文件夹 → 文件列表 ● 前缀 + 标签列表出现自动载入的形状项 | ✅ |
| FR-2 下一步→数据管理 | 落地即见缩略图 ≥N（目录交接） | ✅ |
| FR-3 下一步→训练 | 自动导出产物 data.yaml + 标签文件数=样本数 + 「任务已按数据格式自动选择」 | ✅ |
| FR-4 开始训练→真训练 | 状态「训练完成」；应用日志「训练开始: task=seg」+「epochs_completed=2」；seg_final.pt >1MB（模拟产物不可能） | ✅（6.48MB） |

## 3. 交付物

- `tests/uia/test_wizard_chain_real_train.py`（@uia，默认 ignore 手动跑；
  exe 默认 / AVA_UIA_SOURCE=python 双模式适配）
- **排障战果（本用例首次实跑抓到的真缺陷）**：ultralytics 自带 AMP 检查
  （check_amp）按运行 CWD 找 `yolo26n.pt`，权重挪进 `_internal` 后永远
  miss → 联网下载 → 弱网悬挂训练（exe stdout 捕获实证"Corrupt cache
  re-downloading"）。修复：`_ensure_amp_asset()` 冻结态把随包资产幂等落
  到运行 CWD（train_epoch 内挂接，amp 开启时）+2 单测钉住。
- 顺手沉淀的断言口径：瞬态状态（已载入/数据集统计）会被同链后续状态毫秒
  级覆盖——断言用持久证据（● 前缀/磁盘产物/终态任务提示）。
