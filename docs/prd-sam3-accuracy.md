# PRD：SAM3 标注精度优化（W47 · lite · 取证结案）

## 定档声明

- 档位：🟡 L2（S1「SAM3标注不准确，要优化」+ S3 留痕）
- 确定性：低→高（测量先行）；影响半径：小（仅 adapter 内部 + 文档）；可逆：双向门
- 终态：**不改推理行为**（裁剪窗试验无增益已回滚）；产出=量化基线 + 域上限证明 + 概念词指导 + 可复用评估工具

## 1. 背景

用户反馈 SAM3 标注不准确。以极柱 GT（12 缺陷图，LabelMe 标注）量化定位误差来源。

## 2. 测量结论（scripts/eval_sam3_accuracy.py，确定性复现）

| 路径 | 基线 | 结论 |
|---|---|---|
| 点击（质心→polygon） | mean IoU 0.559 / median 0.611 / ≥0.5 占比 67% / 3-12 图零命中 | **已触零样本域上限** |
| **Oracle 上界**（GT 框提示 + 紧凑裁剪） | mean 0.546 / median 0.660 | 完美提示也无增益 → 分辨率/提示非瓶颈 |
| 裁剪窗 768/512/384/256/192 | mean 0.33-0.42（无增益，中位反降） | **已回滚** |
| ε 简化损耗（2.0→0.5） | 0.455→0.463（+0.008） | 非杠杆，保持 ε=2.0 |
| 实例选择（argmax vs 含点击点） | 0.463 vs 0.456 | 净中性，保持 argmax |
| 概念 AUTO | 全词精确率 0% 除 "scratch"（**32%/覆盖 57%**）、"mark"（11%/68%） | 概念词域敏感；"hole" 高分全误检（分数≠命中） |

## 3. 决策

1. 推理行为维持 W46 原状（回滚试验代码；单测 28 绿 + 基线数字逐位复现验证）。
2. `build_amg_detector` docstring 更新为 GT 实测口径的概念词指导（scratch 有效；hole 高分≠命中）。
3. `scripts/eval_sam3_accuracy.py` 留档为精度回归工具（未来调参/换模型的对照基线）。

## 4. 后续路径（超出本轮，需用户决策）

- **真正越过 0.55-0.65 上限**：需域适配训练（极柱 ~800 标注图微调 SAM3 解码器/LoRA）——训练波次立项时以 eval 脚本为验收标尺。
- 现阶段定位建议：SAM3 交互模式作为**预标注**（IoU~0.6 起草 + 人工修边），AUTO 概念模式在极柱域用 "scratch"。

## 5. 门禁（S3 留痕）

探索=S1 指令+三栏闭环（分辨率假设经 oracle 否证）；PRD=本文档；收尾=主门禁复跑 + 基线复现断言。
